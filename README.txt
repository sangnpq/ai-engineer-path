Mở index.html để sử dụng ngay. Không cần cài thư viện hay API key.

XUẤT BẢN GITHUB PAGES
1. Tạo repository trên GitHub (trống).
2. Đưa toàn bộ nội dung thư mục này, bao gồm .github/workflows/pages.yml,
   lên nhánh main. Có thể dùng git hoặc giao diện Upload files của GitHub.
3. Vào Settings → Pages → Source → GitHub Actions.
4. Chạy workflow Publish GitHub Pages trong Actions nếu chưa tự chạy.
5. URL xuất hiện trong Settings → Pages hoặc kết quả workflow.
Site dùng đường dẫn tương đối nên hỗ trợ cả project Pages và user Pages.

SỬ DỤNG
- Điều hướng 9 màn hình bằng thanh bên.
- Chỉnh sửa hồ sơ để thay mục tiêu, lịch bắt đầu và phút học/ngày.
- Thêm/chỉnh sửa/xóa mục ở mỗi màn hình; bộ lọc kết hợp chủ đề,
  trạng thái, ưu tiên và tìm kiếm.
- Thời gian dự kiến các tuần ban đầu là 300 phút (60 phút × 5 buổi).
  Thay nhịp học không tự ghi đè kế hoạch từng tuần đã chỉnh.
- Tiến độ tổng = tuần hoàn thành / tổng số tuần. Giờ học = tổng phút thực tế.
- Điểm năng lực do bạn hoặc reviewer nhập theo rubric, không tự xác nhận.
- Đánh dấu Tentative khi giả định, kế hoạch hoặc bằng chứng chưa chắc chắn.
- Quyết định & trở ngại: ghi phương án, lý do, người phụ trách và bước xử lý
  trong nội dung; dùng trạng thái Hoàn thành khi đã giải quyết.
- Xuất JSON định kỳ; Nhập JSON để khôi phục hoặc chuyển thiết bị.

GIỚI HẠN LƯU TRỮ
Dữ liệu nằm trong localStorage của trình duyệt, theo địa chỉ site.
Không đồng bộ tài khoản, thiết bị hoặc GitHub; người khác không thấy thay đổi
của bạn. Xóa dữ liệu trình duyệt có thể mất tiến độ. Bản mở từ file và bản
GitHub Pages có vùng dữ liệu riêng: hãy dùng xuất/nhập để chuyển dữ liệu.
Không lưu bí mật, token, dữ liệu khách hàng hay nội dung công việc nhạy cảm.
Font trực tuyến là tùy chọn; mất mạng vẫn có font hệ thống và chức năng chính.

NỘI DUNG
Lộ trình 24 tuần và 60 phút/ngày chỉ là đề xuất tentative. Không có thành tích
AI nào được giả định sẵn. Nền tảng hiện tại giữ theo thông tin người dùng.
Nguồn chính thức được liên kết trong Thư viện tài nguyên; luôn kiểm tra phiên
bản và ngày truy cập trước khi áp dụng API vào công việc.
